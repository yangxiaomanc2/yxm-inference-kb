# 大模型推理优化 · Inference Atlas

直接用浏览器打开 `index.html` 即可使用，无需安装依赖或启动服务。

## 内容

- 12 个模块、48 个技术单元：基础、模型结构、硬件与性能、KV 核心、KV 进阶、量化、算子、编译、引擎、分布式、成本评测、前沿。
- 每个技术单元包含学习目标、知识细目、易错边界、实践与验收。
- KV Cache、量化、算子开发三条精通路径。
- 24 周学习计划、6 个综合项目、实验记录模板。
- 单卡 GQA/MHA 的容量与简化 Decode 下界计算器。
- 趋势假设、验证指标、反例与论文/官方资料入口。

## 操作

- 搜索支持中英文术语和多个空格分隔的关键词；按 `/` 聚焦搜索。
- 点击知识点打开详情，按 Esc 或关闭按钮返回。
- 勾选完成状态。进度只存在当前浏览器中，不会上传。
- 左侧底部可导出/导入 JSON；导入会合并已有进度。
- 可将知识点链接 `index.html#topic-paging` 收藏为直达入口。
- 在浏览器中打印或另存为 PDF，可获得页面摘要；知识点完整细目在弹窗和 `curriculum.js` 中。

## 文件

- `index.html`：网站入口及静态说明、公式。
- `styles.css`：响应式样式。
- `curriculum.js`：完整知识大纲与扩展内容。
- `app.js`：搜索、筛选、详情、进度与估算器。
- `verify.py`：使用 macOS JavaScriptCore 的零依赖逻辑校验脚本。

网站运行不依赖 CDN、框架或后端。外部论文、官方文档需要联网访问。字体优先使用设备已有字体。移动端同样可使用搜索、知识点详情和勾选；桌面侧栏提供进度导入导出。

不同浏览器对 `file://` 页面本地存储的行为不同，迁移或更换浏览器前请导出进度。若浏览器限制文件协议，可在此目录启动任意静态 HTTP 服务（例如 `python3 -m http.server 8000`），然后打开 `http://localhost:8000`；注意文件协议与 HTTP 地址的进度存储相互独立。

## 公式与适用范围

计算器默认示例是通用 8B 级 GQA 配置，不声称对应某个 checkpoint 的精确规格。

- 权重裸容量：`P × weight_bits / 8`。
- 常规等长 KV：`2 × L × B × T × Hkv × dh × kv_bits / 8`。
- 理想带宽项：`(权重字节 + 已有 KV 字节) / 有效带宽`。
- 线性层计算项：`2 × P × B / 有效算力`。
- 简化单步下界取两项最大值，**未计入 Attention 计算、通信与调度**，不能当作实测延迟。
- 容量上限扣除用户设置的预留比例，但不另外精确建模 scales、工作区、量化对齐、图池或内存碎片。

不适用于直接估算 MLA、MoE、TP/PP、多层混合窗口或 prefix 共享。请按模块中的方法分别建模。低比特选项仅表示数学容量，不承诺设备/后端支持。

## 内容审校

整理日期：2026-10-21。参考用户提供的 L0–L6 大纲扩展，修正了 Prefill 平方复杂度的泛化、MLA/TP 的绝对化、Triton 跨后端路径的泛化，以及单位 token 成本重复扣除利用率的问题。

对 vLLM 的 Quantized KV Cache 与 Disaggregated Prefilling 官方页面进行了在线核对。其他资料为优先阅读入口，不表示逐页验证全部版本或已在指定设备上复现。`latest` 文档可能为开发预览，部署前需核对稳定版本。

本网站未在目标加速卡上运行任何性能实验；其中没有虚构性能数据。趋势内容是带适用条件的研究假设。24 周用于建立系统能力与初步作品集，不能保证在六个月内精通领域全部知识。
